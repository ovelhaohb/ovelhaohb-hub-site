Instalar no Windows

Siga este guia para baixar e instalar o OvelhaoHB Hub Idle no Windows. Os nomes e telas podem variar de acordo com o formato do arquivo publicado na Release.

1. Baixe o instalador

  1. Volte à central de downloads e escolha um arquivo destinado ao Windows.
  2. Se o site não identificar o arquivo automaticamente, abra as Releases oficiais e confira o nome e as notas da versão.
  3. Espere o download terminar antes de abrir o arquivo.

2. Instale o aplicativo

  1. Abra o arquivo baixado, por exemplo, um instalador com extensão .exe ou .msi, se esse formato estiver disponível.
  2. Siga as instruções exibidas pelo instalador. Leia cada tela antes de confirmar.
  3. Quando a instalação terminar, abra o OvelhaoHB Hub Idle pelo menu Iniciar ou pelo atalho criado, se houver.

Se o Windows mostrar um aviso de segurança

Não ignore o aviso automaticamente. Confirme que o arquivo veio do repositório oficial e que o nome corresponde à versão publicada. Se o Windows informar que o editor é desconhecido, só prossiga se você confia na origem e verificou o arquivo. Nunca desative a proteção do Windows para instalar um arquivo cuja origem não foi confirmada.

Problemas comuns

  • O arquivo não abre: confirme que o download terminou e que o arquivo corresponde à arquitetura do seu Windows.
  • O site não mostra o instalador: acesse a Release oficial e confira a lista completa de arquivos.
  • O aplicativo não inicia: consulte as notas da versão e abra uma solicitação de suporte no repositório com a mensagem de erro.
