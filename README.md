# OvelhaoHB Hub Idle — site

Site estático com visual gamer escuro/neon e mascote de ovelha, preparado para GitHub Pages.

## Arquivos para a raiz do repositório
Envie o conteúdo desta pasta para a raiz do repositório do site: `index.html`, `.nojekyll`, `assets/` e `tutoriais/`. Não envie apenas a pasta externa.

## Publicação
No GitHub, abra **Settings → Pages**. Em **Build and deployment**, selecione **Deploy from a branch**, branch `main`, pasta `/(root)` e clique em **Save**.

## Downloads
O site consulta as Releases públicas de `ovelhaohb/ovelhaohb-hub-idle` e tenta reconhecer os instaladores pelo nome. Se os nomes não identificarem claramente o sistema, os botões levam à página oficial de Releases. Confira os nomes dos arquivos antes de divulgar.
