Instalar no macOS

Use sempre os arquivos publicados no repositório oficial.

  1. Abra a página oficial de Releases do projeto no GitHub.
  2. Baixe o pacote indicado para macOS, se estiver publicado.
  3. Abra o arquivo (.dmg ou .pkg) e siga as instruções incluídas.
  4. Se o sistema bloquear a abertura, confira a origem do arquivo e consulte as notas da versão antes de alterar configurações de segurança.
