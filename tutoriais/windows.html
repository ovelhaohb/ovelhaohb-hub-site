Instalar no Windows

Use sempre os arquivos publicados no repositório oficial.

  1. Abra a página oficial de Releases do projeto no GitHub.
  2. Baixe o arquivo indicado para Windows, se estiver publicado.
  3. Se for um instalador (.exe ou .msi), abra-o e siga as instruções exibidas.
  4. Se for uma versão portátil, extraia o arquivo e siga as instruções incluídas no pacote.
