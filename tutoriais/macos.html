Instalar no macOS

Este guia orienta a instalação no Mac. Antes de baixar, confirme se o pacote publicado é compatível com seu computador (Apple Silicon ou Intel).

1. Escolha o pacote correto

  1. Abra a central de downloads e procure o pacote destinado ao macOS.
  2. Confira as notas da Release e a arquitetura suportada. Não presuma que um pacote serve para todos os Macs.
  3. Se não encontrar um arquivo, confira as Releases oficiais.

2. Instale conforme o formato

  • Se o arquivo for .dmg: abra a imagem de disco e siga as instruções incluídas no pacote. Se houver um app para copiar, normalmente ele é movido para a pasta Aplicativos.
  • Se o arquivo for .pkg: abra o instalador e siga as etapas exibidas.
  • Se for outro formato: siga as instruções fornecidas na Release. Não tente abrir um formato incompatível.

Se o macOS bloquear a abertura

Confirme a origem do arquivo e consulte as notas da versão antes de qualquer alteração de segurança. O macOS pode bloquear aplicativos que não estejam assinados ou notarizados. Não contorne o bloqueio se não puder confirmar que o arquivo é oficial e íntegro; procure uma versão assinada ou orientação do mantenedor.

Problemas comuns

  • “Não é compatível com este Mac”: confira a arquitetura e os requisitos mínimos indicados na Release.
  • Aplicativo não abre: verifique as notas da versão e as permissões solicitadas.
  • Pacote não aparece: consulte a lista completa de assets na Release.
